* For future agents
This is a backlog of improvements to the Emacs ACP (Agent Client
Protocol) client.  The module lives at
=config/emacs/lisp/mutecipher-acp.el=.  The protocol reference is
https://agentclientprotocol.com.

Workflow: pick a =TODO= or =NEXT=, confirm scope with the user, then
flip it to =DONE= in this file when it ships.  Use =[#A]= / =[#B]= /
=[#C]= as the priority scale:

- =[#A]= — parity blockers for replacing the ~claude~ CLI.
- =[#B]= — polish that makes the experience feel production-ready.
- =[#C]= — ambitious / nice-to-have.

Repo notes:

- The Emacs config is literate: most runtime code is tangled from
  =config/emacs/config.org=.  Standalone modules under
  =config/emacs/lisp/= (including =mutecipher-acp.el=) are edited
  directly — don't touch a generated =config.el=.
- Commit style is conventional commits (~feat(emacs):~,
  ~fix(emacs):~, ~refactor(emacs):~, …), per the project =CLAUDE.md=.
- Line-number anchors below reflect the file at the time of writing
  and will drift — use them as a starting point, not gospel.

* ACP client (mutecipher-acp.el)
** DONE [#A] @-mention file attachments in prompts
The input hint advertises =@ file= but =mutecipher-acp--do-prompt=
only sends a single text content block.  Extend the prompt vector to
include =resource_link= / =resource= content blocks populated from an
=@=-completion UI.
Anchor: config/emacs/lisp/mutecipher-acp.el:1336

** DONE [#A] Inline diff view for Edit/Write tool calls
A proposed edit currently collapses to =⏺ Edit(path)=.  Render a
=diff-mode= hunk inline (or route multi-file edits through ediff) so

factor before letting the agent touch real code.
Anchor: config/emacs/lisp/mutecipher-acp.el:462

** TODO [#B] Colorize inline diff blocks
=mutecipher-acp--insert-diff-block= currently inserts each diff line
as plain text.  A first pass defined =mutecipher-acp-diff-added= /
=-removed= / =-hunk-header= faces with explicit =:background= and
=:extend t= (inheriting from the built-in =diff-*= faces), but the
backgrounds did not render on the liminal-light theme — neither the
inherited nor the explicit ones.  Investigate: face-inheritance
composition?  A =face-remapping-alist= somewhere in the session
buffer?  Theme override?  Something about how =font-lock= in the
session mode interacts with our text-property faces?  Once colors
render reliably, restore a =mutecipher-acp--diff-line-face= dispatcher
that paints +/−/@@ lines.
Anchor: config/emacs/lisp/mutecipher-acp.el:481

* ACP client — agentic-IDE data layer
Roadmap from the 2026-05-25 gap analysis on what =mutecipher-acp-*=
needs to support a Cursor-style agentic dev environment.  These items
are distinct from the polish/UX backlog above — they're about the data
model under the transcript, not what's rendered on top of it.

Related items already tracked above (don't re-file):
- MCP server passthrough (#A) — covers the MCP slice.
- Surface usage and cost (#B) — covers per-turn tokens / cost.
- Rewind / edit last message (#B) — subsumed by "stable node
  identity" below (id-per-message is the prerequisite).
- Persist sessions across Emacs restarts (#B) — subsumed by
  "on-disk transcript serialization" below (the existing item is
  just the cwd→session-id index; the bigger lift is serializing
  the transcript itself).
- project.el / magit integration (#C) — adjacent to but smaller
  than "repo signal as structured input" below.

** DONE [#A] Stable node identity (UUIDs on user/assistant/tool-call)
Only =macp-turn= has an =id=, and only =macp-tool-call= has
=call-id=; =macp-user= / =macp-assistant= / =macp-thought= / =macp-plan=
have no addressable identity.  Without ids you cannot fork from a
turn, edit-and-rerun an arbitrary user message, or restore the file
checkpoint associated with a turn.  Add a =:uuid= slot to every
addressable struct, populate at enter-time, and key a per-session
hash off them for O(1) lookup.
Anchor: config/emacs/lisp/mutecipher-acp-model.el:19

** DONE [#A] On-disk transcript serialization
=session/load= replays state from the agent, but the agent isn't a
durable store — auth changes, model deprecations, or simple GC will
drop history.  Persist the full =macp-node= list per session to
=~/.cache/emacs/acp/<session-id>.eld=, plus an index
=~/.cache/emacs/acp/index.eld= of =(id agent cwd title last-active
model)= for the session picker.  Extends the lighter "persist
sessions" item above.
Anchor: config/emacs/lisp/mutecipher-acp-session.el (load/new paths)

** TODO [#A] Change-set as a first-class object
Per-turn diffs currently live on individual =macp-tool-call= structs
for rendering only.  Add a =macp-change-set= struct hung off
=macp-turn= that groups every file mutation in a turn, tracks
per-hunk staged / accepted / rejected state, and stores a pre-edit
snapshot for restore.  This is the single biggest "agentic IDE" gap —
no review-changes panel, no checkpoint/restore, no partial accept
without it.
Anchor: config/emacs/lisp/mutecipher-acp-model.el:40 (tool-call),
         config/emacs/lisp/mutecipher-acp-tools.el (diff plumbing)

** TODO [#B] Pinned context / always-include attachments
Attachments are extracted per-prompt at composer-send time
(=mutecipher-acp-composer.el=).  Add a =:pinned-attachments= slot to
=macp-session= for "always include these paths" plus a slot for
selection-based context (region from another buffer staged for the
next prompt — Cursor's "Add to chat" gesture).
Anchor: config/emacs/lisp/mutecipher-acp-composer.el,
         config/emacs/lisp/mutecipher-acp-model.el:65 (session struct)

** TODO [#B] Repo signal as structured input
Today the agent reads git status / diff / branch / LSP diagnostics
ad-hoc via tool calls.  Add a =macp-repo-state= struct refreshed on
buffer save and exposed to the composer, so the user can stage "send
current diff" / "send failing tests" / "send diagnostics for this
file" without manual Bash dispatch.  Broader than the existing
project.el / magit item.

** TODO [#C] Nested tool-calls (subagent trees)
=macp-tool-call= is flat in the ewoc.  Add a =:parent-call-id= slot so
that when a tool call spawns subagent work (e.g. Task tool), the
children can render under the parent in a collapsible tree.
Anchor: config/emacs/lisp/mutecipher-acp-model.el:40

** TODO [#C] Cross-session search index
Once transcripts are on disk, build a per-project index keyed on
content so "find the conversation where we discussed X" works without
hand-grepping =.eld= files.  Depends on the on-disk serialization
item above.

** TODO [#C] Context-window pressure / compaction events
Add a =:context-pct= slot to =macp-session= and a =macp-compaction=
node kind so when the agent compacts, the event is visible in the
transcript (and the header-line can warn before compaction hits).
Adjacent to the usage/cost item but distinct — usage is per-turn,
compaction is a window-pressure event.
